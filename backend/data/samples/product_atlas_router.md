# Atlas 5000 Router — Product Information

Document type: Product Information
Product: Atlas 5000 Router
SKU: ATL-5000

## Overview

The Atlas 5000 Router is an enterprise-grade edge router for branch offices.

## Features

- The Atlas 5000 Router has the feature Dual-WAN Failover for redundant internet
  links.
- The Atlas 5000 Router has the feature VPN Concentrator supporting up to 500
  simultaneous tunnels.
- The Atlas 5000 Router has the feature Zero-Touch Provisioning for remote setup.

## Specifications

- The Atlas 5000 Router has spec Throughput with value 10 and unit Gbps.
- The Atlas 5000 Router has spec Port Count with value 24 and unit ports.
- The Atlas 5000 Router has spec Power Draw with value 65 and unit watts.

## Compatibility

- The Atlas 5000 Router is compatible with the Atlas 5000 Rack Mount Kit.
- The Atlas 5000 Router is compatible with the Nimbus Cloud Manager.
